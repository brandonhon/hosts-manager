Plain file, careful edits

    
hosts-manager keeps a normal hosts file. Categories are comment markers and switched-off entries are commented out, so the operating system and anyone reading it by hand see exactly what they expect.

    

      
# @category
Categories
Put your dev, staging and blocklist entries in their own groups and switch a whole group with disable -c staging.

      
profile
Profiles
Name a set of categories and turn exactly those on with profile development.

      
restore 1
A backup before every change
Each write is backed up first, and restore 1 puts the previous file back.

      
--dry-run
Safe to try
Changes need sudo. With --dry-run you can see what any command would do without it.
