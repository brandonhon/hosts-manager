# hosts-manager logo

The `#` that comments out a line in a hosts file, with its top bar turned into a
switch that is on. hosts-manager's whole job is switching hosts entries on and
off, and the `#` is how it switches them off.

## Files

| File | Use it for |
|---|---|
| `hosts-manager-icon.svg` | The default mark, on its blue tile. Release pages, the website header, anywhere the logo stands alone. |
| `hosts-manager-icon-512.png`, `-256.png`, `-128.png` | The same, where SVG is not accepted. |
| `hosts-manager-glyph-on-light.svg` | Without the tile, next to text on a light background. |
| `hosts-manager-glyph-on-dark.svg` | Without the tile, next to text on a dark background. |
| `hosts-manager-mono.svg` | One color, for stickers, prints and single-ink use. The knob is a hole; recolor by changing its two `#0F141B` values. |
| `hosts-manager-favicon.svg` | Browser tab icon. Heavier bars and a bigger knob, drawn to stay legible at 16 and 32 px. |
| `favicon.ico` | Browser tab icon for older browsers: 16, 32 and 48 px in one file. |
| `favicon-16.png`, `favicon-32.png` | The tab icon as PNGs. |
| `apple-touch-icon.png` | 180 px home-screen icon. Square and opaque, because iOS rounds the corners itself. |

The SVGs are the source; the PNGs and the `.ico` were rendered from them.

## Colors

| Name | Hex | Used for |
|---|---|---|
| Host blue | `#1D74C4` | The tile, and the bars on light backgrounds |
| Switch green | `#5FD16B` | The switch, in every color version |
| Terminal | `#0F141B` | Dark backgrounds, and the one-color mark |
| Paper | `#F5F7FA` | Light backgrounds |

## Using it

- Keep clear space around the mark of at least a quarter of its width.
- Keep the switch green and on (knob to the right) in every color version except
  the one-color mark.
- Don't stretch, rotate or recolor the mark, and don't add effects to it.
